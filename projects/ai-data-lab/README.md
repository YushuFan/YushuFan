# AI.Data Lab × TechBridge

**Food distribution, severe weather, and disaster exposure in Georgia**

This collaborative Emory AI.Data Lab project examined how environmental conditions relate to food-bank platform activity. My original R analyses explored food-bank-to-pantry transactions and donor offers alongside weather and disaster measures. The original team study reported an association between disaster severity and transaction volume (**p = .006**).

This folder preserves the original analysis scripts as authored. It is an archival snapshot, not a cleaned or independently reproducible release: the source workbooks and partner data are not included.

## Original files

- `Agency Express Transactions.Rmd` — transaction activity analysis.
- `Agency Express Transactions copy.Rmd` — later working version.
- `Donor Express Offers.Rmd` — donor offer analysis.
- `Donor Express Offers copy.Rmd` — later working version.

## How to read this project

The R files are kept unchanged to preserve the original work. They refer to source spreadsheets that are not part of this public folder, so they will not run as-is. A separate [Python + SQL reanalysis](https://github.com/YushuFan/food-bank-disaster-analysis) revisits one question with a different disaster definition; its estimate is not a like-for-like replication of the original result.

The research was collaborative. The scripts above were authored by Yushu Fan; other team deliverables and contributions are not claimed as solely authored.
